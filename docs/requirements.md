# 要件定義書 — Trello風タスク管理アプリ

## 1. プロジェクト概要

| 項目 | 内容 |
|------|------|
| プロジェクト名 | Raise App — Task Management |
| 目的 | 学習用のTrello風タスク管理アプリを段階的に開発する |
| 対象ユーザー | 開発者自身（学習・個人利用） |
| 開発方針 | バージョンを重ねながら機能と技術スタックを拡張していく |

---

## 2. バージョンロードマップ

| バージョン | 技術スタック | 主な目的 |
|-----------|-------------|---------|
| **v1** | React + localStorage | Reactの基本・state管理を理解する |
| **v2** | React + localStorage | コンポーネント設計・UIを深める |
| **v3** | React + JSON Server | 非同期処理・HTTP通信を理解する |
| **v4** | React + Node.js + DB | サーバーサイド・データベースを理解する |
| **v5** | フルスタック | 認証・デプロイ・実用アプリとして完成 |

---

## 3. v1 機能要件

### 3.1 画面構成

```
┌─────────────────────────────────────────┐
│  タスク管理ボード                          │
├─────────────┬──────────────┬────────────┤
│  未着手      │   進行中      │   完了     │
│             │              │            │
│ [カード]     │  [カード]     │  [カード]  │
│ [カード]     │              │            │
│             │              │            │
│ [+ 追加]    │  [+ 追加]    │  [+ 追加] │
└─────────────┴──────────────┴────────────┘
```

### 3.2 機能一覧

| # | 機能 | 詳細 |
|---|------|------|
| F-01 | カード追加 | 各カラムにテキスト入力でカードを追加できる |
| F-02 | カード削除 | カードに削除ボタンがあり、クリックで削除できる |
| F-03 | カード移動 | 「→」ボタンで次のカラムへカードを移動できる |
| F-04 | データ永続化 | ページをリロードしてもデータが消えない（localStorage使用） |

### 3.3 非機能要件

| # | 項目 | 内容 |
|---|------|------|
| N-01 | カラム | 「未着手」「進行中」「完了」の3カラム固定 |
| N-02 | スタイル | シンプルなCSSで視認性を確保する |
| N-03 | データ形式 | JSON形式でlocalStorageに保存する |

### 3.4 v1スコープ外（後バージョンで対応）

- ドラッグ＆ドロップ（v2）
- カードの編集（v2）
- カラムの追加・削除（v2）
- サーバーとの通信（v3以降）
- ユーザー認証（v5）
